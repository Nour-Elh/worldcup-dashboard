# worldcup-dashboard
Django dashboard project for data management and visualization
This repository contains a Django-based dashboard application designed to manage and visualize World Cup data.

## Files Included

* manage.py
* config/
* worldcup/
* data_source/

## Tools Used

* Python
* Django
* SQLite
* HTML / CSS
* Data Visualization

## Features

* Dynamic dashboard interface
* World Cup data management
* Structured data display
* Web application architecture

## Purpose

Build an interactive web dashboard to organize and present World Cup data through a user-friendly interface.
